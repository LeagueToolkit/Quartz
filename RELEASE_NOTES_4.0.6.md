# 4.0.6 restores important workflows, improves performance, and polishes the Rust edition.

## What's new

- Reworked WAD Explorer indexing and search for much faster results.
- Restored WAD previews, hash extraction, BIN decompiling, and multi-WAD loading.
- Improved SKN model textures, chromas, materials, skybox, and ground rendering.
- Restored Asset Extractor model previews, skin IDs, and Jade actions.
- Fixed Port parent/child emitter detection and automatic texture loading.
- Restored Bumpath workflows, custom prefixes, Quick Repath, and optional VFX splitting.
- Improved the built-in file explorer with sorting, file details, copy/paste, and marquee selection.
- Added automatic updates and a Markdown-powered post-update showcase.
- Improved startup behavior, bundled resources, production downloads, and general UI consistency.

## Fixes

- Fixed WAD Explorer rescan crashes and slow repeated searches.
- Fixed broken production wallpapers and remote asset loading.
- Fixed model submesh toggles rebuilding the entire renderer.
- Fixed Audio Splitter drag-and-drop opening files in the main window.
- Fixed native folder selection, Explorer actions, and Jade launching.

Thank you for testing the new Quartz. Please report any remaining issues on GitHub.
