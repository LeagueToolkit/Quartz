# 4.1.4 is a smaller update: some new tools from Wiko, and a good round of fixes.

## What's new

- **Merge all bins in a folder** into one file, in a single step. Thanks to Wiko.
- **NoSkinLite**: copy one skin onto every skin slot for a champion at once. Thanks to Wiko.
- **Fix VFX Shape**: point it at a bin or a whole folder and it repairs them. Thanks to Wiko.
- Sound Banks: drop a mod folder onto either panel, not just the main one.
- Sound Banks: create empty folders in the reference panel and drag sounds into them to sort your tracks.
- Sound Banks: right-clicking an empty area now opens a menu.

## Improvements

- Deleting all emitters from a system is dramatically faster. It also undoes in one step now, instead of bringing the emitters back one at a time.
- Buttons no longer flash and grey out every time you click something in Port.
- The BIN viewer in WAD Explorer lets you select and copy text properly, including Ctrl+A for the whole file.
- The background effect is now off by default on a fresh install. You can still turn it on in Settings.

## Fixes

- Fixed bins saving without a line some tools need, which stopped Jade from opening them.
- Fixed audio preview failing with a "no supported source" error.
- Fixed dragging sounds between panels in Sound Banks.
- Fixed the folder count in Sound Banks not updating, and empty folders sticking around after you moved everything out.

Thank you for testing Quartz. Please report any remaining issues on GitHub.
