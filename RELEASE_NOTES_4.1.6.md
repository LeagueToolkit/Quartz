# 4.1.6

## What's new

- **Animation mode in Port.** There's a VFX / ANM toggle at the bottom. Flip it and both columns show the skin's animation clips, where you can edit them, add and delete events, and drag clips over from the donor. Still a work in progress, so expect rough edges.

## Fixes

- Fixed Extract and Repath staying greyed out in Asset Extractor after setting your League folder.
- Fixed bins sent from Flint to Paint not opening. Thanks to DexalGT.
- The hash database now updates itself in the background instead of only when you click the button in Settings, so new skins stop looking like they're missing.

Thank you for testing Quartz. Please report any remaining issues on GitHub.
